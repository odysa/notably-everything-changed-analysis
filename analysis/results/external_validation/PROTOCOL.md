Exactly 40 main-conference research papers each from EMNLP 2019, 2020, 2024 and 2025 will be selected by ascending SHA256(`20261019:` + official paper ID), excluding front matter. Explicit official long-paper labels will be used where available; if no long/short labels exist, select all main research entries without inferring length from page counts, report mixed lengths and proceedings-volume differences, and retain the fixed body-word gate. The selected identifiers will be frozen privately, with public anonymous hashes and source hashes, before PDF retrieval. Original source-ID overlap must be zero. Authors may overlap. No failed downloads or extraction exclusions will be replaced.

PDF processing uses the unchanged original scripts/extract.py, with its private helper dependency injected from the committed byte-identical extractor_snapshot.py. Original policy-section removal and minimum 1,500 body-word gate apply. Raw metadata, PDFs and extracted text stay outside git at the private data directory (`$BEFORE_AFTER_AI_DATA_DIR/external_emnlp/` by convention). Only anonymous numeric features are released.

Train logistic regression ONLY on original main-ten-venue pre/post samples, from the frozen numeric snapshot. Estimate feature mean and population SD ONLY from pooled training pre samples; replace zero SD by one; clip standardized values to [-8,8]. Fixed C=0.3, max_iter=2000, otherwise sklearn defaults. No EMNLP fitting, normalization, threshold calibration, tuning or feature selection. Apply the fitted model once to eligible external papers.

Report download/extraction/eligibility counts by year and era; pooled AUC and four pairwise pre-year/post-year AUCs; raw mean gaps for functional riders, core interpretive riders, and summed Additionally/Notably openers. Conditional 95% percentile intervals use 2,000 paper bootstrap replicates within year, seed 20261019. These do not represent uncertainty over venues or common year shocks. No causal, AI-authorship, author-disjointness, or public-readiness claim follows. Any extraction compatibility failure or incomplete official metadata is a stop with an explicit limitation, not an alternate corpus search.
